# YangYang AI Buddy — 마인크래프트 베드락 애드온

갤럭시 A16의 Minecraft Bedrock Edition(안드로이드)을 대상으로 만든 애드온 초안입니다.

## 포함 기능
- `yangyang:buddy`라는 소환 가능한 동료 몹
- `yangyang:spawn_egg`라는 전용 소환 아이템(아이템 아이콘 등록 포함)
- 노란 얼굴과 파란 옷을 입은 간단한 자체 모델(돼지 기본 모델 대신 사용)
- 플레이어를 바라보고 가까이 따라오도록 설정
- 체력 24

## 설치
1. [애드온 제작 페이지](https://yangyang-minecraft-addon.vercel.app/)를 열고 `.mcaddon 만들기`를 누릅니다.
2. 다운로드한 `YangYang_AI.mcaddon` 파일을 눌러 Minecraft로 가져옵니다.
3. 월드 설정에서 행동 팩과 리소스 팩을 활성화합니다.
4. 크리에이티브 인벤토리에서 양양이 소환 아이템을 찾아 사용하거나, 치트가 켜진 테스트 월드에서 `/summon yangyang:buddy`를 실행합니다.

## 중요
- 애드온은 실제 온라인 AI와 대화하지 않습니다. 게임 안에서 움직이는 동료 몹의 시작 버전입니다.
- 이 모델은 새로 만든 간단한 블록형 캐릭터이며, 게임 안에서의 표시와 동작은 아직 실제 기기에서 검증되지 않았습니다.
- 기존 월드에서 시험하기 전에 월드를 복사해 백업하세요.
