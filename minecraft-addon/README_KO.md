# YangYang AI Buddy — 마인크래프트 베드락 애드온

갤럭시 A16의 **Minecraft Bedrock Edition(안드로이드)** 을 대상으로 만든 작은 애드온 초안입니다.

## 포함 기능
- `yangyang:buddy`라는 소환 가능한 동료 몹
- 플레이어를 바라보고 가까이 따라오도록 설정
- 체력 24
- 분홍색 돼지 기본 모델을 이용해 별도 텍스처 없이 표시하도록 구성

## 설치
1. 이 저장소의 `minecraft-addon` 폴더 안에 있는 Behavior Pack과 Resource Pack 파일을 각각 ZIP으로 다운로드합니다.
2. 파일 확장자를 각각 `.mcpack`으로 바꾼 뒤 Android에서 열어 Minecraft로 가져옵니다.
3. Minecraft에서 월드 편집 > 행동 팩과 리소스 팩으로 이동해 두 팩을 활성화합니다.
4. 치트가 켜진 월드의 채팅에서 실행합니다: `/summon yangyang:buddy`

## 중요
- 이 저장소에는 팩의 **소스 파일**이 들어 있습니다. 지금은 설치용 `.mcaddon` 바이너리를 빌드하거나 게임 안에서 실행 테스트하지 않았습니다.
- 마인크래프트 버전에 따라 엔티티 동작이나 텍스처 경로를 조정해야 할 수 있습니다.
- 이 애드온은 실제 온라인 AI와 대화하지 않습니다. 게임 안에서 움직이는 동료 몹의 시작 버전입니다.
- 기존 월드에서 시험하기 전에 월드를 복사해 백업하세요.
