아직 미구현

실제 부팅 가능한 ISO

UEFI/GRUB 부트 메뉴, OS 이미지 검증, 실제 PC/VM 부팅 테스트.

중요: 웹페이지나 메뉴만으로 운영체제를 실제 설치할 수는 없습니다. Windows 1.0–3.x는 DOS 기반 실행 경로가 필요하고, 최신 Windows는 하드웨어·펌웨어·라이선스 요구 사항이 따로 있습니다. 실제 설치/부팅 기능은 별도로 개발하고 검증해야 합니다.

통합 개발 순서

  1. 기존 NeoOS-2 및 YangVM 코드를 그대로 보존하고 별도 기능으로 연결.
  2. OS별 지원 아키텍처, 펌웨어, 라이선스, 메모리/저장공간 요구 사항을 데이터로 정리.
  3. 가상 머신 기능을 별도 실험 브랜치에서 검증하고 안전한 가상 디스크 생성/삭제 흐름 구현.
  4. 별도의 부팅 ISO 프로젝트에서 UEFI/GRUB 멀티부팅을 구현하고 QEMU 테스트부터 시작.
  5. 실제 테스트가 통과한 기능만 다운로드 페이지에 제공.
