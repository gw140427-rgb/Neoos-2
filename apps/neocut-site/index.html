다운로드 안내: 빌드 기록을 열고 페이지 아래쪽의 Artifacts에서 파일을 선택하세요. 빌드 중이거나 실패한 실행에는 파일이 없을 수 있고, 아티팩트는 보관 기간이 지나면 만료될 수 있습니다.

현재 제공 기능

클립 관리여러 영상 불러오기, 순서 변경, 구간 설정
자막 오버레이자막 문구·색상·크기 조절
배경 음악오디오 파일과 음량 설정
프로젝트 파일편집 설정 JSON 저장 및 불러오기
개발 중인 버전: WebM 내보내기는 실험적 기능이며 전문 편집기의 모든 기능을 제공하지 않습니다. 프로젝트 JSON에는 영상 원본이 포함되지 않으며, 실제 기기 호환성은 검증 중입니다.
