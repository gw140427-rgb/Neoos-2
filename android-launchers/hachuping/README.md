# 하츄핑 런처

Android 8.0 이상을 위한 가벼운 분홍색 홈 런처 샘플입니다.

- 설치된 앱 목록과 아이콘 표시
- 앱 이름 검색 및 실행
- Android 기본 홈 앱으로 선택 가능
- 외부 API 키나 유료 서비스 불필요

## APK 빌드

저장소의 Actions 탭에서 **Build Hachuping Launcher APK** 워크플로를 실행합니다. 완료된 실행에서 `hachuping-launcher-debug-apk` 아티팩트를 다운로드한 뒤 ZIP을 풀고 `app-debug.apk`를 설치합니다.

설치 후 Android 설정의 기본 앱 > 홈 앱에서 **하츄핑 런처**를 선택하세요.

현재 버전은 분홍색 팬 테마 UI이며, 공식 하츄핑 캐릭터 이미지/로고는 포함하지 않습니다. APK 빌드와 실제 기기 테스트는 Actions 결과를 확인해야 합니다.
