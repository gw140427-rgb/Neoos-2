🛡️ Docker 안전 제한

백엔드 적용
  • 게스트 슬롯 4개서버의 MAX_CONTAINERS 값으로 제한돼. 슬롯이 가득 차면 생성 요청을 거절해.
  • 컨테이너 자원 제한기본 256MB RAM · CPU 0.5 · PID 64개
  • 컨테이너 격리Linux capabilities 전체 제거 · no-new-privileges · 호스트 폴더 미마운트
  • 자동 만료기본 30분 뒤 NeoOS 게스트 컨테이너 자동 정리
  • 시스템 컨테이너 보호NeoOS가 만들지 않은 컨테이너와 box·user-vps-*는 변경·삭제하지 않아.
  • 접근 인증32자 이상 토큰을 서버에서 검증. 공개 다중 사용자 계정/소유권 기능은 아직 활성화하지 않아.

Podroid는 휴대폰에서 동작하는 단일 Docker 노드야. 컨테이너는 완전한 VM이 아니고 같은 Android/Linux 커널을 공유하므로, 공개 사용자에게 임의 명령 실행을 제공하지 않도록 해.

NeoOS 인스턴스에 건우의 ask-cli를 한 줄로 깔면 터미널에서 한국어로 AI에게 물어보고 명령까지 실행할 수 있어. 의존성 0개(python3만 필요).

curl -fsSL https://raw.githubusercontent.com/gw140427-rgb/ask-cli/main/install.sh | bash

설치 후 3단계

  • ask --config — 무료 API 키 등록 (Groq 무료 키를 넣으면 0.3초 응답).
  • ask "도커 안 쓰는 이미지 정리해줘" — 명령을 제안하고 [y/N] 확인 후 실행.
  • export PATH="$HOME/.local/bin:$PATH" — 설치 직후 ask가 안 잡히면 한 번 실행.

Ubuntu/Debian/Alpine 모두 python3만 있으면 돼. 설치 스크립트는 python3가 없으면 먼저 설치하라고 알려 줘.
