NeoOS 인스턴스에 건우의 ask-cli를 한 줄로 깔면 터미널에서 한국어로 AI에게 물어보고 명령까지 실행할 수 있어. 의존성 0개(python3만 필요).

curl -fsSL https://raw.githubusercontent.com/gw140427-rgb/ask-cli/main/install.sh | bash

설치 후 3단계

  • ask --config — 무료 API 키 등록 (Groq 무료 키를 넣으면 0.3초 응답).
  • ask "도커 안 쓰는 이미지 정리해줘" — 명령을 제안하고 [y/N] 확인 후 실행.
  • export PATH="$HOME/.local/bin:$PATH" — 설치 직후 ask가 안 잡히면 한 번 실행.

Ubuntu/Debian/Alpine 모두 python3만 있으면 돼. 설치 스크립트는 python3가 없으면 먼저 설치하라고 알려 줘.
