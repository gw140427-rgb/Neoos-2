NeoOS는 기본 관리 기능을 유료 구독으로 잠그지 않습니다. 서버처럼 실제 자원이 필요한 기능은 공급자 비용을 먼저 확인하고, 사용자가 이해하고 승인한 뒤에만 이용하도록 하는 것이 원칙입니다.

실제 자원 비용은 별도

NeoOS가 대신 부담한다고 약속하지 않습니다. 클라우드 공급자에서 실제로 발생하는 비용을 기준으로 안내합니다.

사용량 기반

VPS 컴퓨팅

인스턴스 종류, 실행 시간, 리전 등 공급자 청구 기준에 따릅니다.

사용량 기반

추가 저장 공간

디스크와 오브젝트 스토리지의 실제 용량·요금 기준을 따릅니다.

선택형 검토

고급 백업·팀 기능

추후 필요성이 확인되면 선택 기능으로 검토합니다. 기본 기능을 막지 않습니다.

결제와 가격 공개 원칙

  • 현재 이 페이지는 요금 정책 안내이며, 결제·자동 청구 기능이 활성화됐다는 뜻이 아닙니다.
  • 확인되지 않은 가격이나 무료 한도를 임의로 표시하지 않습니다.
  • 유료 기능을 출시한다면 가격, 과금 단위, 예상 월 비용, 초과 시 동작을 먼저 공개합니다.
  • 서버 생성 전 예상 비용과 공급자 청구 가능성을 안내하고, 사용자 확인 없이는 유료 자원을 시작하지 않는 방향으로 설계합니다.
  • 비용 한도·중지 기능은 실제 백엔드에서 검증되기 전까지 보장된 기능으로 표시하지 않습니다.
  • 광고로 기본 화면을 도배하거나 필수 기능을 광고 시청 뒤에 숨기지 않습니다.
현재 상태: 정책 안내 페이지

중요한 안내

NeoOS Cloud는 외부 클라우드 공급자의 자원을 사용할 수 있습니다. 서버를 실행하면 공급자 계정에 비용이 발생할 수 있으므로, 실제 요금은 해당 공급자의 공식 가격표와 계정의 청구 화면에서 확인해야 합니다. 이 페이지는 가격 견적이나 결제 약관이 아닙니다.
