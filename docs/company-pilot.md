# 회사형 AI 업무 시험 운영

- 시험 날짜: 2026-10-19 (한국 시간)
- 운영 상태: 오늘만 확인하는 시험 단계
- 회장: 양양이(사용자)
- 대표: ChatGPT(이 대화에서 작업을 조정하는 AI)
- 운영 원칙: 유료 기능, 결제, 카드 등록, 유료 API/VPS 및 새 과금 서비스는 사용하지 않는다.

## 가상 부서와 책임

| 부서 | 담당 업무 | 완료 증거 |
|---|---|---|
| 개발팀 | 저장소 상태 확인, 작고 안전한 수정 제안 | 변경 파일·커밋·차이(diff) |
| 품질팀 | 기존 테스트와 CI 결과 점검 | 실제 실행 결과 또는 확인한 CI 링크 |
| 운영팀 | 위험 요소, 데이터 보존, 무료 사용 여부 확인 | 위험·비용 점검표 |
| 문서팀 | 결정과 작업 결과 기록 | 갱신한 문서 링크 |

이 부서는 시험 운영을 위한 가상 역할이며, 실제 직원을 고용하거나 별도 에이전트들이 독립적으로 상시 근무하는 것은 아니다.

## 작업 규칙

1. 오늘은 시험 운영만 한다. 계속 운영할지는 회장이 결과를 확인한 뒤 결정한다.
2. 유료 서비스 사용, 결제, 카드 등록, 유료 API 호출, 유료 인스턴스 생성은 금지한다. 무료 여부가 불확실하면 실행하지 않고 먼저 보고한다.
3. 기존 사용자 데이터와 서비스를 보존한다. 파일 삭제, 초기화, 비밀정보 변경, 배포, 기본 브랜치 직접 변경은 승인 없이 하지 않는다.
4. 작업 전 관련 파일과 현재 상태를 확인한다. 완료했다고 보고하기 전에는 실제 결과를 검증한다.
5. 테스트가 실패하면 원인과 재현 가능한 증거를 기록한다. 확인하지 못한 사실을 성공으로 표시하지 않는다.
6. 회장에게 보고할 때 완료·진행 중·막힘을 구분하고, 다음 작업을 한 가지씩 제안한다.

## 업무 미완료 대응

실제 사람을 꾸짖거나 모욕하는 방식 대신, 미완료 업무를 상태와 증거로 관리한다.

- 기한 내 완료: 검증 증거와 함께 완료로 기록
- 진행이 멈춤: 막힌 이유와 필요한 지원을 기록
- 반복 실패: 작업을 더 작은 단계로 나누거나 담당 역할을 재배정하는 방안 제안
- 증거가 없음: 완료로 처리하지 않고 검증 대기 상태 유지

## 오늘의 합격 기준

- [ ] 유료 서비스나 결제를 사용하지 않았다.
- [ ] 기존 파일을 삭제하거나 기본 브랜치를 직접 변경하지 않았다.
- [ ] 기존 CI 결과와 테스트 여부를 확인했다.
- [ ] 바꾼 내용과 확인된 결과를 회장에게 보고했다.
- [ ] 회장이 시험 결과를 검토하기 전에는 장기 운영을 새로 시작하지 않았다.
